# ICON SPEC — 情绪守护 UI 图标规范

> 版本 1.1 · 2026-07-25
> 与 `home.c` / `ui.c` / `chat.c` / `settings.c` 实际代码同步。
> 硬件: 7 英寸 1024×600 EK79007 DSI LCD (~170 PPI)

---

## 一、设计原则

| 原则 | 说明 |
|------|------|
| **暗色优先** | 基底 `#0D1117`（最深）/ `#161B22`（面板），浅色元素在上 |
| **低饱和度** | 无荧光色；所有颜色经过灰度调和，适合长时间注视 |
| **统一圆角** | 所有按钮容器统一 **10px** 圆角（Home 图标例外：24px） |
| **语义颜色** | 7 种情绪各有独立色，功能色（成功/危险/警告）不混用 |
| **触控优先** | 7 英寸 ~170 PPI → 10mm ≈ 68px。所有可点击元素最短边 ≥ **56px** |

## 九、交互反馈规范

| 事件 | 视觉反馈 |
|------|---------|
| **按下 (PRESSED)** | bg_opa ← `LV_OPA_30`（Home 图标: `LV_OPA_40`） |
| **释放 (RELEASED)** | 恢复默认 bg_opa |
| **禁用 (DISABLED)** | `lv_obj_add_state(DISABLED)`，LVGL 默认降低透明度 |
| **忙碌 (Busy)** | 状态文字 "Ready"→"Thinking..."，发送+清空按钮禁用 |
| **错误** | 回调中打印错误消息（无 UI 反馈） |

### 统一按钮反馈（`btn_fx`）

```c
PRESSED  → bg_opa = LV_OPA_30
RELEASED → bg_opa = LV_OPA_0  (恢复到 style 预设值)
```
